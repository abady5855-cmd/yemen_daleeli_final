# تقرير الدين التقني (Technical Debt Report)

## 📉 ملخص الديون التقنية
تم تحديد بعض النقاط التي تحتاج لتحسين مستقبلي لضمان استدامة المشروع على المدى الطويل.

---

## 🔍 الديون الحالية
### 1. البحث النصي (Full-Text Search)
- **الوضع الحالي:** يتم استخدام استعلامات Firestore البسيطة (`isGreaterThanOrEqualTo`).
- **المشكلة:** البحث محدود ولا يدعم البحث بكلمات جزئية أو أخطاء إملائية.
- **الحل المستقبلي:** دمج **Algolia** أو **Typesense**.

### 2. معالجة الصور (Image Optimization)
- **الوضع الحالي:** يتم عرض الصور مباشرة من الروابط.
- **المشكلة:** قد يؤدي ذلك لاستهلاك بيانات كبير وبطء في التحميل للصور عالية الدقة.
- **الحل المستقبلي:** استخدام **CachedNetworkImage** مع تقنيات ضغط الصور في Cloud Functions.

### 3. الاختبارات (Testing)
- **الوضع الحالي:** وجود اختبارات وحدة محدودة للنماذج (Models).
- **المشكلة:** نقص في اختبارات الـ Integration والـ UI (Widget Tests).
- **الحل المستقبلي:** رفع تغطية الاختبارات لتشمل الـ UseCases والـ Repositories.

### 4. التدويل (Internationalization)
- **الوضع الحالي:** النصوص مكتوبة باللغة العربية مباشرة في الكود مع وجود حقول En في الـ Models.
- **المشكلة:** صعوبة إضافة لغات جديدة مستقبلاً.
- **الحل المستقبلي:** استخدام ملفات **ARB** ونظام `flutter_localizations`.
